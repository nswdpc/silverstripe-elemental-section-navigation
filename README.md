# Section Navigation element for Silverstripe

A block to display a list of links to child pages, or pages in current level.

## Installation

This is a fork of [dynamic/silverstripe-elemental-section-navigation](https://github.com/dynamic/silverstripe-elemental-section-navigation)

```sh
composer require dynamic/silverstripe-elemental-section-navigation
```

> Add this repository's URL as a [repository entry](https://getcomposer.org/doc/05-repositories.md) in your project's composer.json

## Example usage

Adds a block to display a list of links to child pages, or the pages in the current level. Useful for sidebar navigation.
